THE PASSPORT MODEL · DESIGN-PARTNER PROTOTYPE

One living record for every AI system.

DESIGNED · NOT A CERTIFICATION

A Passport is a persistent identity and context record for a model or agent. It connects configuration, permitted actions and evidence to the same system over time. This website illustrates the target record; it does not issue certificates or persist real Passports.
