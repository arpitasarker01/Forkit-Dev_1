TESTER CHECKLIST

Six short checks on your own computer.

1 · Install safely

Use only a reviewed, explicitly provided private test build. Tell us your OS/version and installation result. Do not disable system security protections, antivirus or Gatekeeper.

2 · Detect real tools

Launch Claude Code, Codex, Gemini CLI, Cursor or Windsurf if installed. Record detected/not detected without sending command lines, names, account details or files.

3 · Activity evidence

Work briefly, then let the tool idle. Verify Working appears only with measurable CPU-time activity; an installed or idle process must not be counted as AI-active.

4 · Local models

For Ollama or LM Studio, test available-but-not-loaded versus running/loaded if the runtime supports that distinction.

5 · Restart + consent

Restart the local application. Check history is preserved. Test anonymous contribution OFF, Allow, Stop Sharing and local ID reset; note no upload should occur while collector rollout is disabled.

6 · Privacy audit

Review outbound requests with your own network inspector. Flag any content, prompt, file path, process ID, hostname, username, secret or model name. Share findings without including the sensitive value itself.
